# Portfólio — Luiz Felipe Fernandes

Meu site pessoal, feito com React e Vite, em português e inglês.

## Como rodar

```
npm install
npm run dev
```

## Como gerar a versão final

```
npm run build
```

A pasta `dist` é o site pronto para publicar.

## Onde editar

- Textos (português e inglês), links e contato: `src/data.js`
- Foto: `src/assets/foto.jpg`
- Currículo: `src/assets/curriculo.pdf`
- Fotos das redes (opcional): `src/assets/foto-instagram.jpg`, `foto-linkedin.jpg`, `foto-github.jpg`

## Créditos

Componentes TechText e CardSwap: React Bits (reactbits.dev).
